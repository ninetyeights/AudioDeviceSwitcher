已完成：

- 版本号与安装包默认版本统一为 1.7.0。
- 定时执行结果回读、等待会话后的持续确认、立即重试。
- 备份格式 v2 包含定时计划与补执行开关，接受 v1 备份；导入前检查时间及方案引用，重置导入计划的生效时间与执行记录。
- 回归检查覆盖结果确认、重试、备份序列化、合并计划、旧版兼容及禁止补执行导入前任务。
- 12 个窗口离线布局渲染检查；Release 单文件自包含构建。
- 发布工作流加入回归检查、布局渲染及标签与项目版本一致性检查。
- 本地 55 项检查通过，12 个窗口布局渲染通过；Inno Setup 编译成功，安装包位于 `dist/AudioDeviceSwitcher-Setup-1.7.0.exe`。已从已安装的 1.6.1 升级到 1.7.0，安装返回成功且无需重启；方案、预设和计划数据与升级前备份一致。

用户已确认手动验收 1–5 项通过：方案选择／切换、未运行应用路由重置、会话出现后自动设置、仅输出静音、定时切换。后续备份导入确认与校验修改已编译通过，尚未手动验收。自动操作音频的验收已按用户要求停止。

以下扩展场景未全部覆盖，保留后续验收：

- 应用退出后切换到无应用规则的方案，再启动应用，验证输入／输出跟随系统。
- 实际定时到点、进程退出重启、电脑休眠恢复；未到首次时间点不得补执行。
- 蓝牙断连重连、方案锁定、路由部分失败及重试，并听辨真实声音。
- 下拉框、键盘导航和 125%／150% 缩放。
- 备份当前用户数据后，从旧安装版升级，验证数据、快捷方式、自启动和卸载入口。
- 编译器提示管理员安装与 HKCU 用户注册项混用：需验证提升权限后的自启动和通知注册属于预期用户，尤其使用另一管理员账户安装时。

当前限制：备份跨多个数据文件合并并非整体事务；发生磁盘写入失败时可能已有部分数据导入，应保留导入前备份。核对成功仅指设备和路由设置，不代表真实音频链路测试成功。
